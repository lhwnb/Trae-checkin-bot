# Trae 每日签到机器人

自动完成 Trae IDE 的每日签到：**每 24 小时**自动点击左下角账号 → 在弹出菜单中点击"签到"按钮。

## 文件说明

| 文件 | 作用 |
|---|---|
| `run.bat` | 双击启动（自动完成环境准备并运行机器人） |
| `start_bot.ps1` | 启动脚本：建虚拟环境、装依赖、校准模板、运行机器人 |
| `checkin_bot.py` | 机器人主程序（窗口激活 + 按钮模板匹配 + 24 小时循环） |
| `capture_templates.py` | 按钮模板校准工具（首次使用必须运行） |
| `config.json` | 配置：签到间隔、匹配置信度、重试策略等 |
| `enable_autostart.ps1` | 可选：注册开机自启计划任务 |
| `logs/checkin.log` | 运行日志 |
| `logs/screenshots/` | 每次点击后的结果截图、失败时的现场截图 |
| `templates/` | 按钮模板图片（校准后生成） |

## 快速开始

1. **双击 `run.bat`**
   - 首次运行会自动创建 `.venv` 虚拟环境并安装依赖（需要几分钟，请保持联网）
   - 依赖装好后会自动进入**按钮校准**：
     - 第 1 步：先在 Trae 里点开左下角账号、打开签到弹窗并**保持打开**，回控制台按回车，然后在全屏截图上**拖动框选"签到"按钮**
     - 第 2 步：关闭弹窗，按回车，框选左下角的**账号区域**
     - 第 3 步（可选）：今天已签到的话可框选"已签到"按钮；直接回车跳过
2. 校准完成后机器人立即执行一次签到，之后**每 24 小时自动循环**
3. 保持 `run.bat` 的窗口开着即可；关闭窗口 = 停止机器人

## 测试是否正常工作

```bat
.venv\Scripts\python.exe checkin_bot.py --once
```

然后查看 `logs\screenshots\` 里最新的截图，确认签到结果。

## 开机自启（可选）

右键 `enable_autostart.ps1` → "使用 PowerShell 运行"，注册后每次登录 Windows 自动启动。
取消自启：

```powershell
Unregister-ScheduledTask -TaskName 'TraeCheckinBot' -Confirm:$false
```

## 常见问题

- **窗口移动/缩放/改显示缩放会失效吗？** 不会。机器人每轮都会重新读取窗口位置和大小；模板匹配只在 Trae 窗口区域内进行，与窗口位置/大小无关；匹配本身支持**多尺度缩放**（0.8~1.5 倍，见 `config.json` 的 `match_scales`），即使以后改了 Windows 显示缩放（100%↔125%↔150%）或界面元素大小变化也能识别。另外每次成功点击后会把按钮的相对偏移自动记录到 `logs/learned_offsets.json`，万一模板失配，就用这个**自学习的偏移**兜底（相对窗口/账号按钮定位，不会瞎点）。

- **提示"未找到 Trae 窗口"**：确认 Trae 已启动（最小化到托盘也可以，机器人会自动还原窗口）。机器人按**进程名**（`Trae CN.exe`/`Trae.exe`）识别窗口，不受窗口标题影响；若仍找不到，运行 `python debug_windows.py` 查看窗口列表，把标题关键字填到 `config.json` 的 `window_keywords`。
- **提示"未找到签到按钮"**：看 `logs\screenshots\` 里的失败截图。若是 Trae 更新导致界面变化，重新运行 `python capture_templates.py` 录制模板；也可把 `config.json` 里 `confidence` 从 0.85 降到 0.80 试试。若截图里看到的是**其他程序**（说明 Trae 被全屏游戏/程序遮挡），签到前关掉那个全屏程序即可（机器人会自动把 Trae 提到前台，但压不住真正的全屏独占程序）。
- **点击位置偏移**：检查 Windows 显示缩放（设置 → 系统 → 显示 →"缩放与布局"）。脚本已做高 DPI 适配，一般无需处理；若仍偏移，重新校准模板。
- **想改签到周期**：编辑 `config.json`，`interval_hours` 改间隔小时数；或把 `schedule_mode` 改成 `"daily"` 并用 `daily_time` 指定每天的执行时间（如 `"09:00"`）。
- **如何停止**：关闭黑色控制台窗口，或按 `Ctrl+C`；运行中也可把鼠标快速甩到屏幕左上角紧急中止。

## 说明

- 机器人通过模拟鼠标点击实现，运行时请勿手动操作鼠标（点击前有 0.4~1.2 秒随机停顿，已被 FAILSAFE 保护）。
- 本工具仅供个人学习交流使用。
